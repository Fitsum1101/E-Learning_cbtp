# E-Learning_cbtp

# Functional Requirements

- **User Registration and Login**: Allow users to create accounts, log in securely, and manage profiles (e.g., update name, age, language preference).
- **Course Browsing and Enrollment**: Enable users to browse available courses (e.g., computer literacy, web development, coding basics) and enroll in courses freely (with potential future limit of 1 course at a time).
- **Content Access and Learning**: Provide access to view or download learning materials such as text, videos, PDFs, and guides, available in Amharic and Afaan Oromoo for better comprehension.
- **Progress Tracking**: Allow users to mark lessons as complete and track overall progress (e.g., completion percentage).
- **Certificate Issuance**: Issue a certificate upon course completion with a unique verification code.
- **Feedback and Communication**: Enable users to submit suggestions or report issues via a contact/feedback form.
- **Admin Panel**: Allow admins to upload, edit, delete, and organize course content (e.g., modules, lessons), manage users (e.g., view profiles, monitor activity), and monitor platform usage and activity logs.
- **All student reading materials come from Markdown files uploaded by the admin. When these files are fetched by the frontend, they are converted to HTML for display in the e-learning platform**
